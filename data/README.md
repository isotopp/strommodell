# Lokale Modelldaten

Dieses Verzeichnis enthält nicht versionierte Downloads und abgeleitete
Referenzdaten. Für jeden Download wird neben der Datei eine Metadatendatei
gespeichert: URL, Abrufzeitpunkt (UTC), Datenjahr, Zeitzone, Auflösung,
Einheiten und SHA-256-Prüfsumme.

`tests/fixtures/` enthält dagegen kleine, versionierte Testdaten. Ergebnisse
von Szenarioläufen gehören nach `results/`.
